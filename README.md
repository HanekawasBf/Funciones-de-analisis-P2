# Funciones de analisis P2

Programa en Python que captura una función lineal como texto (ej. `2x + 3`),
extrae `m` y `b`, y evalúa `y = mx + b` para `n` valores de `x` mediante un
menú interactivo en consola.

## Archivos

- `parser_funcion.py` — extrae m y b del texto.
- `evaluador.py` — evalúa y = mx + b.
- `main.py` — menú principal.

Ejemplo de función válida: `2x + 3`, `-1.5x - 4`, `x + 5`, `x`, `5`.
